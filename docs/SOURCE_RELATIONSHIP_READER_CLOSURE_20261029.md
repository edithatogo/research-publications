its independent pin. Model-document hashes reuse the canonical plain sorted JSON
helper; row/context hashes reuse the reviewed typed `fingerprint` helper. CLI
input is strict JSON and new outputs use the existing private exclusive writer.

The context must bind exact full source/canonical arrays, counts, canonical key
set and full field inventory, explicit projection/snapshot identities, an exact
existing producer expression and the frozen expression-part hash. Canonical
fields must reconcile with all declared Publication columns. Publication keys
must be unique, candidate mappings must be consistent, and missing/ambiguous
canonical mappings remain explicit. Provider and eligibility mappings are exact
per-assertion inputs, never defaults or deductions from identity labels.

qualification remain false. Unknown dates and retraction values remain null.

are rejected rather than flattened into extra facts.

An existing typed producer is required; the helper creates no new source route.

upstream_byte_hash_verification or canonical_source_parity capability produces

## Canonical equivalence and exact supported producer families

The parent-requested key edge follows the established admission/feed rule:
casefold-equivalent CanonicalKeys are rejected even when their literal spellings
differ. Accepted spellings are preserved exactly; no normalization or rekeying
occurs. A dedicated test first reproduced the case-sensitive gap, then verifies
both rejection and literal preservation. The M canonical guard additionally uses
OrdinalIgnoreCase uniqueness; native collation and field/filter parity remain
explicit unqualified execution gates, not a claimed Unicode/collation proof.

The typed adapter is bounded to these already reviewed row families and requires
explicit per-assertion provider/eligibility context plus matching source namespace:

- OpenAlex work, authorship/identifier alias, affiliation/cooccurrence and source
  award/unresolved-award assertions from `source_relationship_evidence`.
- Structured PubMed publication/author/affiliation/cooccurrence, grant and trial
  reference assertions, with the structured-versus-raw provenance distinction.

- Crossref/ARDC award crosswalk assertions/diagnostics and Crossref historical
  NHMRC application-reference assertions/diagnostics from the reviewed packets.

acceptance of every family; each still needs its own exact typed context and

consumer families are not implicitly connected. Unsupported provider/family
